# 🕒 SFML Analog Clock

A desktop application that displays a real-time **analog clock** developed in **C++** using the **SFML** multimedia library. The project demonstrates object-oriented programming, graphical rendering, trigonometric calculations, and real-time animation.

## ⚙️ How It Works

The application retrieves the current system time and computes the rotation angle of each clock hand.

The clock updates continuously to display:

- Current hour
- Current minute
- Current second

Trigonometric functions are used to calculate the end position of each hand before rendering them on the screen. SFML provides the rendering window, drawable shapes and event handling. :contentReference[oaicite:0]{index=0}

## 🚀 Getting Started

### Requirements

- Visual Studio 2022
- SFML 2.6.x
- C++17 compatible compiler

### Installation

Clone the repository:

```bash
git clone https://github.com/bAbderraouf/SFML_Analog_Clock.git
```

Open the solution using Visual Studio.

Configure SFML include directories, library directories and DLL files.

Build and run the project.
